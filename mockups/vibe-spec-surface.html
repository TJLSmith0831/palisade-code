The Vibe shell currently surfaces spec state only through the thread header chip, the spec banner, and the mode badge in the thread list. The full SpecPane (change browser + task progress) and VerifyPane live in the Editor shell's right-rail disclosure. A spec surface in Vibe would bring the linked change's progress and verification state into the Vibe right sidebar as a collapsible disclosure — same data, same API calls, chat stays primary.
