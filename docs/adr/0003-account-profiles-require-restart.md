# Separate local profiles and switch accounts through restart

Local projects, chat history, workspace state, and personal preferences belong to the authenticated Palisade account's local profile. An account switch requires a safe app restart after unsaved work and running sessions are settled, avoiding live changes to storage destinations and cross-account results. Existing local data is imported only through explicit consent with a recovery copy; profiles prevent accidental in-app disclosure, while OS user permissions remain the filesystem security boundary.
